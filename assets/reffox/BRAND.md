# RefFox mascot system

RefFox is the mascot for Nature Reviewer Skills: a skeptical scientific reviewer whose default stance is **“show me the evidence.”**

> **Suspicious by default. Evidence first.**

RefFox represents the project’s core behavior: identify the strongest scientific claim, attack weak links in its evidence chain, and turn valid concerns into actionable revision paths.

## Character

RefFox should feel:

- analytical rather than hostile;
- skeptical of claims, not dismissive of authors;
- technically competent and evidence-first;
- approachable without becoming childish;
- consistent with an open-source scientific/developer tool.

The canonical character has orange-and-cream fox coloring, round black glasses, dark paws, and scientific-review props. Red marks indicate review findings; green marks indicate better-supported revision paths.

## Asset map

| Asset | Role | Recommended use |
|---|---|---|
| `reffox-main.png` | **Canonical primary mascot** | README hero, docs landing pages, announcements |
| `reffox-avatar.webp` | Compact head/avatar | Small cards, profile/icon contexts |
| `reffox-mono.webp` | Monochrome mark | One-color contexts, stamps, subtle document marks |
| `reffox-reviewer.webp` | General scientific review | Review workflow and examples |
| `reffox-bug-found.webp` | Scientific “bug” found | Failure-mode examples and debugging language |
| `reffox-major-concern.webp` | Major concern / warning | High-severity evidence failures |
| `reffox-control-check.webp` | Controls and methods inspection | Validation, controls, methods, reproducibility |
| `reffox-evidence-please.webp` | Request stronger evidence | Unsupported claims, weak validation, missing evidence |

The primary mascot is intentionally the **green-check / upward-evidence-path** version: RefFox is not only a critic; the project should help authors move from a weak evidence chain toward a defensible one.

## Usage rules

- Use `reffox-main.png` as the canonical primary artwork.
- Use `reffox-avatar.webp` when the full mascot would become visually unreadable.
- Use `reffox-mono.webp` for restrained one-color placements.
- Use action stickers as callouts supporting technical content, not as substitutes for technical content.
- Preserve the transparent background and original aspect ratio.
- Do not stretch, recolor, mirror, or add unofficial logos to the character.
- Prefer an approximately **80% technical/scientific : 20% mascot/brand** balance in repository documentation.
- Repository PNG files are optimized derivatives. Avoid repeated lossy re-encoding.

## Language and affiliation boundary

RefFox is an independent project mascot. It must not be presented as a Nature Portfolio, Springer Nature, journal, editor, or referee identity.

Preferred wording:

- “Nature-style scientific review”
- “pre-submission scientific stress testing”
- “domain-aware scientific reviewer skills”

Avoid wording that implies official affiliation, such as “official Nature reviewer” or “Nature’s AI reviewer.”

The repository’s existing affiliation disclaimer remains authoritative:

> This is an independent open-source project. It is not affiliated with Nature Portfolio or Springer Nature.

## Short voice lines

Use sparingly:

- **Your paper has bugs. RefFox tries to find them.**
- **Show me the evidence.**
- **Stronger claims need stronger evidence.**
- **Missing control.**
- **Overclaiming risk.**
- **Revision path available.**
