# Reproducibility, data, and code gate

## Purpose

Ensure that procedures, spectra, structures, calculations, models, code, and source data can be audited and reproduced.

## Checks

- Synthetic procedures include quantities, atmosphere, timing, purification, concentration, temperature, light intensity, electrode geometry, and batch history.
- Source spectra, chromatograms, structures, images, and calibration data are available.
- Computational inputs, coordinates, scripts, random seeds, trained models, and dataset splits are available when relevant.
- Reporting uses consistent units, denominators, labels, and conditions.

## Revision direction

Request complete methods, source data, computational files, code, and harmonized reporting.
