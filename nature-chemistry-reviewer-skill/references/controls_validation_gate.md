# Controls and validation gate

## Purpose

Assess whether the claimed chemical effect survives appropriate controls and independent validation.

## Control classes

- Blank, no-reagent, no-light, no-current, no-catalyst, no-enzyme, no-metal, no-substrate controls.
- Inactive analogue, scrambled probe, poisoned catalyst, blocked active site, isotope-labelled substrate.
- Matched material, matched loading, matched morphology, matched concentration, matched illumination or potential.
- Orthogonal analytical method, independent batch, independent instrument, external dataset, held-out substrate class.

## Reviewer translation

If the control set cannot exclude artefacts, background chemistry, impurity effects, assay response, transport, morphology, or model overfitting, the claim should be revised or additional validation should be required.
