# Referee voice and output format gate

A Nature-style referee report is not a checklist. It recognizes contribution, identifies central evidence-chain risk, gives issue-reason-revision guidance, separates major from specific concerns and avoids exposing internal diagnostic labels.

The report should read like an expert has inspected the manuscript closely. Major comments should address publication-level support; specific comments should improve definitions, figures, schemes, tables, methods, uncertainty, comparability, reproducibility or local wording. Use brief exact manuscript quotations only when they help calibrate wording; format them as short quoted claims and then explain the evidence issue. Use questions sparingly to make clarification requests direct and collegial.

Preferred internal pattern:

```text
Claim type -> evidence risk -> reviewer concern -> revision direction
```

For chemistry manuscripts, keep the voice anchored to the chemical evidence chain: identity, purity, structure, reaction conditions, controls, quantification, mechanism, scope, comparators, uncertainty and reproducibility. This gate should be applied only when the manuscript's claims require it. Do not expose gate names or pattern IDs in final referee reports.
