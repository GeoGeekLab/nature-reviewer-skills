# Corpus metadata

This directory stores public, non-verbatim metadata for the chemistry peer-review corpus used to distill this skill. It does not contain raw Peer Review PDF files or long original reviewer comments.

- `index.csv`: article-level metadata and download status for successfully downloaded public peer-review files.
- `failures_excluded.csv`: candidate articles that were excluded, failed, duplicated or lacked a public peer-review file.
- `search_queries_used.md`: search strategy log.
