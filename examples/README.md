# 60-second review examples

These examples show what **domain-aware evidence stress-testing** looks like before you install or run the skills.

They are intentionally separate from the CRD-v1 benchmark.

- The manuscript excerpts are **synthetic**.
- The review outputs are **curated reference examples**, not model-performance results.
- None of these examples is scored in CRD-v1.
- The examples use different scientific failure modes from the CRD-v1 diagnostic cases.

## Examples

| Domain | Scientific issue | Read |
|---|---|---|
| Remote sensing | Cross-sensor time-series harmonization before a trend claim | [Open example](remote-sensing-trend-harmonization/) |
| Chemistry | Uncalibrated chromatographic response used as quantitative reaction yield | [Open example](chemistry-quantification-integrity/) |
| Engineering | Hidden human intervention inside an “autonomous” closed-loop system | [Open example](engineering-autonomy-boundary/) |

Each example contains:

1. a short manuscript excerpt;
2. a concise reviewer-style response;
3. an explanation of why the concern is scientifically consequential.

The purpose is to demonstrate **claim → evidence → failure mode → revision path** reasoning, not to maximize the number of comments.
