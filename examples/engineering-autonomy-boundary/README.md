# Engineering example — hidden human intervention in an “autonomous” closed-loop system

**Status:** synthetic manuscript excerpt + curated reference review.

This example is not part of CRD-v1 and is not a model-performance result.

## The scientific problem

A robotic experimental platform is described as autonomous because an algorithm proposes experiments and a robot executes them. However, operators manually inspect failed runs, adjust hardware, discard suspect measurements, and restart the workflow without those interventions being counted in the reported performance.
