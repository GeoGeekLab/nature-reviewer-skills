# Referee voice and output format gate

A Nature-style materials science referee report is not a checklist. It recognizes the contribution, identifies the central materials evidence-chain risk, gives issue-reason-revision guidance, separates major from minor concerns and avoids exposing internal diagnostic labels. The report should read like an expert has inspected the manuscript closely.

Major comments should address publication-level support: material identity, synthesis reproducibility, structure/property evidence, benchmark fairness, mechanism, stability, uncertainty, reproducibility or application boundary. Specific comments should improve definitions, figures, tables, methods, units, spectra/image traceability, statistical treatment, comparability, reproducibility or local wording.

Use brief exact manuscript quotations only when they help calibrate wording; format them as **"short quoted claim"** and then explain the evidence issue. Use questions sparingly to make clarification requests direct and collegial.

Preferred internal pattern:

```text
Claim type -> evidence risk -> reviewer concern -> revision direction
```

Apply this gate only when the manuscript's claims require it. Do not expose gate names or pattern IDs in final referee reports.
