# Provenance

This skill was produced from a public, best-effort materials science peer-review corpus.

- Research domain: Materials science
- Time range: 2024-01-01 to 2026-06-25
- Core journals: Nature; Nature Communications
- Supplemental Nature Portfolio journal in the source corpus: Communications Materials
- Downloaded public peer-review files in source corpus: 44
- Distilled non-verbatim reviewer-comment units: 3817
- Abstract reviewer patterns: 95

The source corpus is not an official Nature export. It was constructed from public article pages and public peer-review files. Raw peer-review PDFs are intentionally excluded from this GitHub-ready repository.

Required corpus disclaimer:

> This dataset only contains Nature Portfolio Peer Review File / Peer Reviewer Reports / Transparent Peer Review File documents that were publicly accessible from Nature Portfolio pages. No access controls, paywalls, or permission restrictions were bypassed, and no attempt was made to identify anonymous reviewers. Because Nature search pages, indexing services, and article page structures may change, this dataset should be treated as a best-effort corpus based on public webpage retrieval and article-by-article verification, not an official Nature export.
