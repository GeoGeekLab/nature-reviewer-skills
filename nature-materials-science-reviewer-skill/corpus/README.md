# Source corpus metadata

This folder preserves corpus metadata for the public, best-effort Nature Portfolio materials-science peer-review corpus used to distill `nature-materials-science-reviewer-skill-v1.0`.

It contains article-level metadata, keyword-expansion records, failure/exclusion records, QA records, checksums and a summary JSON. It does not contain raw peer-review PDFs or long original reviewer comments.

The source corpus was built from publicly accessible Peer Review File / Transparent Peer Review File pages for materials-science research articles published from 2024-01-01 to 2026-06-25 in Nature, Nature Communications and Communications Materials.

This metadata package is not an official Nature Portfolio export and should be treated as a public-web, article-verified, best-effort corpus record.
