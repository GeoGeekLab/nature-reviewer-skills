# Engineering Gate Router

Use gates only when triggered by claim type. Do not expose this routing in final reports.

| Claim type | Primary gates | Main risk |
|---|---|---|
| Prototype/platform | claim-evidence, design requirements, validation | Demonstration treated as general platform |
| Superior performance | benchmarking, uncertainty, operating envelope | Unfair comparison or selected metric |
| Scalable manufacturing | fabrication, scaling, reproducibility | Yield and process window absent |
| Autonomous system | automation AI, benchmarking, reproducibility | Hidden human intervention or narrow search space |
| Robot capability | robotics control, validation, operating envelope | Task/environment diversity too narrow |
| Biomedical translation | bioengineering, safety, controls | Translation stronger than biological evidence |
| Mechanism | mechanism causality, controls, model sensitivity | Correlation treated as causal explanation |
| Simulation/model | model assumptions, sensitivity, validation | Model substitutes for independent evidence |
