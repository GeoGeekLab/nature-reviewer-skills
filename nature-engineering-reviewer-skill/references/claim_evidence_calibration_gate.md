# Claim-Evidence Calibration Gate

Preferred structure:

```text
Claim type → evidence risk → reviewer concern → revision direction
```

Common engineering calibrations:

- Prototype ≠ platform.
- Exemplar device ≠ manufacturable process.
- Laboratory optimum ≠ operating envelope.
- Simulation ≠ independent validation.
- Benchmark table ≠ fair comparison unless constraints match.
- Plausible mechanism ≠ demonstrated mechanism.
