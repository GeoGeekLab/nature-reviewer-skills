# Atmospheric science gate index

These gates provide concise, transferable controls for Nature-style atmospheric-science review. They should be activated by the manuscript's own claims and evidence chain, not applied mechanically.

| Gate | Primary use |
|---|---|
| claim_evidence_calibration_gate.md | Calibrate title, abstract, conclusion, and interpretation to demonstrated evidence. |
| observational_product_reanalysis_gate.md | Evaluate station, campaign, satellite, radar/lidar, aircraft, and reanalysis products. |
| sampling_event_representativeness_gate.md | Test sampling frames, events, baselines, domains, seasons, and composites. |
| scale_resolution_boundary_gate.md | Match process scale with model grid, footprint, vertical level, aggregation, and boundaries. |
| model_physics_sensitivity_gate.md | Stress-test parameterizations, forcing, initialization, tuning, ensemble design, and structural assumptions. |
| ai_weather_climate_model_gate.md | Review AI weather/climate models for leakage, fairness, physical fidelity, rollouts, extremes, and OOD regimes. |
| aerosol_cloud_radiation_gate.md | Separate aerosol, CCN, cloud, meteorological, adjustment, and radiative pathways. |
| chemistry_emissions_budget_gate.md | Review emissions, chemistry, transport, deposition, source attribution, and budget closure. |
| extreme_event_attribution_gate.md | Review event definitions, counterfactuals, risk ratios, internal variability, and allocation logic. |
| trend_signal_detection_gate.md | Review trends, internal variability, forced signals, autocorrelation, baselines, and field significance. |
| circulation_mechanism_causality_gate.md | Review causal mechanism, circulation, feedback, moisture, energy, radiative, chemical, and mass-budget closure. |
| statistical_uncertainty_gate.md | Review validation independence, uncertainty hierarchy, ensemble design, spatial dependence, and metrics. |
| reproducibility_data_code_gate.md | Review data versions, code, configurations, trained weights, workflow provenance, and source data. |
| novelty_related_work_positioning_gate.md | Calibrate novelty type and comparison with closest relevant work. |
| detail_audit_gate.md | Check definitions, units, signs, thresholds, captions, labels, and method consistency. |
