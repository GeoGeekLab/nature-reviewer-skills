# Aerosol-cloud-radiation microphysics gate

Use when claims depend on aerosol-cloud interactions, CCN, cloud radiative effects, cloud adjustments, or aerosol indirect forcing.

Claim type → evidence risk → reviewer concern → revision direction

- Aerosol-cloud susceptibility claim → meteorology and cloud regime not separated → co-variation may drive result → stratify by regime and meteorological controls.
- Radiative forcing claim → droplet or optical metric only → forcing pathway is incomplete → propagate uncertainty through cloud and radiation response.
- Aerosol mechanism claim → aerosol amount, size, composition, and vertical structure conflated → CCN pathway is ambiguous → diagnose microphysical variables separately.
