# Sampling, event selection, and representativeness gate

Use when inference depends on selected stations, domains, events, seasons, campaign periods, composites, or baselines.

Claim type → evidence risk → reviewer concern → revision direction

- Event-based conclusion → subjective threshold or selected case window → result may be selection-dependent → define selection rules and test alternatives.
- Regional atmospheric mechanism → narrow domain or period → generality is not established → add regime, season, domain, or baseline sensitivity.
- Composite result → uneven sampling or autocorrelation → effective sample size is overstated → report sample counts and dependence handling.
