# Claim-evidence calibration gate

Use when the manuscript's title, abstract, conclusions, or discussion claim more than the evidence chain demonstrates.

Claim type → evidence risk → reviewer concern → revision direction

- Broad atmospheric mechanism → local or diagnostic evidence only → conclusion is over-generalized → narrow the claim or add cross-regime support.
- Direct-observation language → proxy, product, retrieval, model, or index evidence → target variable is not directly measured → validate the proxy-target relation.
- Forcing, impact, or operational claim → process metric only → implication exceeds demonstrated pathway → add quantitative propagation or soften interpretation.
