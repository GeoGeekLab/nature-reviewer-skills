# Detail audit gate

Use throughout the review to catch errors that materially affect interpretation rather than cosmetic wording alone.

Claim type → evidence risk → reviewer concern → revision direction

- Quantitative conclusion → unclear units, signs, thresholds, or sample sizes → reader cannot verify the result → standardize definitions and labels.
- Figure-based argument → captions omit filters, levels, or uncertainty → figure meaning is ambiguous → include key design details in captions.
- Supplement-dependent method → main text lacks essential parameters → central result is hard to assess → move essential definitions into the main methods.
