# Statistics, uncertainty, and validation gate

Use when headline conclusions depend on statistical inference, validation, benchmark metrics, ensembles, field significance, or uncertainty propagation.

Claim type → evidence risk → reviewer concern → revision direction

- Validation claim → validation data are not independent → skill is inflated → document independence and use holdout or cross-product tests.
- Spatial-field claim → multiple testing or spatial dependence ignored → significance is overstated → apply field significance or spatially aware uncertainty.
- Quantitative headline claim → only fit uncertainty shown → structural uncertainty missing → separate statistical, product, model, and sampling uncertainty.
