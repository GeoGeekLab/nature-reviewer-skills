# Claim–evidence protocol

For every major concern, record: the manuscript claim, direct evidence, inference step, hidden assumptions, plausible alternatives, uncertainty, scope boundary, and the smallest revision that could resolve or calibrate the claim. Do not request an experiment merely because it is interesting. Explain which decision-relevant uncertainty the requested action resolves.

Never invent lines, figures, references, data, or experimental details. When an input cannot be inspected, state that limitation and reduce confidence.
