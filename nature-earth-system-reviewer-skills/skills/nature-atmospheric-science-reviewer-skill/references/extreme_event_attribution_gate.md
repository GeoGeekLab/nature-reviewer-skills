# Extreme-event and counterfactual attribution gate

Use when claims attribute atmospheric extremes, risks, damages, or event probabilities to forcing agents, emitters, sectors, or regions.

Claim type → evidence risk → reviewer concern → revision direction

- Event-attribution claim → event definition or threshold is flexible → risk ratio may be definition-dependent → predefine event metrics and sensitivity.
- Counterfactual claim → factual model not evaluated for event dynamics → attribution may rest on biased simulations → evaluate circulation, thermodynamics, and extremes.
- Allocation claim → risk ratio uncertainty not propagated → responsibility framing is over-precise → quantify uncertainty and clarify allocation logic.
