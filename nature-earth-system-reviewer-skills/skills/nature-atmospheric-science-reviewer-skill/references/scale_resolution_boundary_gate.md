# Scale, resolution, and boundary consistency gate

Use when process scale must match observation footprint, model grid, time averaging, vertical level, domain design, or boundary forcing.

Claim type → evidence risk → reviewer concern → revision direction

- Boundary-layer or cloud-process claim → coarse grid or aggregated footprint → subgrid physics are inferred beyond resolution → add scale-aware diagnostics.
- Mesoscale circulation claim → domain or boundary conditions constrain response → mechanism may be boundary artefact → test domain and boundary sensitivity.
- Vertical-coupling claim → pressure-level or layer mismatch → evidence samples a different atmospheric layer → align diagnostics across levels.
