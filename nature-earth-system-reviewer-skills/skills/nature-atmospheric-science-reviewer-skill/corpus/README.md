# Atmospheric peer-review corpus metadata

This folder records the public-source basis used to build the atmospheric-science reviewer skill. It is a metadata-only release layer for provenance and quality control.

The skill repository does not redistribute raw Peer Review File PDFs, long reviewer comments, editor decisions, author rebuttals, or reviewer-identifying information. Raw public PDFs were used only as corpus construction inputs. The released skill stores abstract reviewer patterns, gate summaries, metadata, and non-verbatim indices.

## Files

```text
index.csv
failures_excluded.csv
keyword_expansion.csv
qa_report.csv
checksums.sha256
summary.json
```

The corpus is a transparent best-effort corpus, not an official complete dataset from any journal or publisher.
