# Example manuscript summary

Title: Satellite observations reveal recent global river-water-level variability

Main claim: A global satellite-altimetry product detects increasing variability in river water levels and attributes the pattern to recent climate change.

Evidence chain: Sentinel-class altimetry -> virtual river stations -> water-level anomaly metrics -> trend/variability analysis -> hydroclimate interpretation.

Key review risks: river stage versus discharge; short-record attribution; validation coverage; human regulation; reproducibility of quality flags and station masks.
