# Hydrological variable validity gate

Check whether the measured or modelled variable can support the claim: stage versus discharge, TWS versus groundwater, precipitation anomaly versus drought impact, flood extent versus hazard, concentration versus load, surface area versus storage.

Preferred internal pattern:

```text
Claim type -> evidence risk -> reviewer concern -> revision direction
```

This gate should be applied only when the manuscript's claims require it. Do not expose gate names or pattern IDs in final referee reports.
