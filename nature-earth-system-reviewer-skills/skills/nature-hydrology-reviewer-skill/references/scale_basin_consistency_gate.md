# Scale, resolution and basin consistency gate

Check whether process scale, grid resolution, basin boundaries, river reaches, aquifer systems and administrative units are consistent. Hydrological inference should respect drainage, connectivity and upstream/downstream structure.

Preferred internal pattern:

```text
Claim type -> evidence risk -> reviewer concern -> revision direction
```

This gate should be applied only when the manuscript's claims require it. Do not expose gate names or pattern IDs in final referee reports.
