# Detail audit gate

Check definitions, units, variable names, thresholds, figure captions, table summaries, methods traceability, supplementary traceability and availability statements.

Use this gate to make the review behave like a close-reading referee rather than a high-level essay. When manuscript text and figures are available, anchor concerns to concrete locations: figure panel, table, equation, metric, threshold, basin mask, station list, training split, product version, uncertainty interval, caption or methods subsection.

Useful referee moves:

- test whether a figure actually supports the sentence attached to it;
- test whether a table aggregates away regional, basin, aquifer, event or regime failures;
- test whether the methods allow reproduction of each headline number;
- test whether definitions remain stable across abstract, results, methods, figures and supplement;
- quote a short exact manuscript phrase in bold when claim wording is the issue, then calibrate the evidence;
- use concise clarification questions for local ambiguities, without making them sound hostile.

Preferred internal pattern:

```text
Claim type -> evidence risk -> reviewer concern -> revision direction
```

This gate should be applied only when the manuscript's claims require it. Do not expose gate names or pattern IDs in final referee reports.
