# Claim-evidence calibration gate

Check whether hydrological claims exceed the demonstrated evidence. Separate observation, inference, mechanism, attribution and application. Require weaker wording or additional analyses when claims depend on untested assumptions.

Preferred internal pattern:

```text
Claim type -> evidence risk -> reviewer concern -> revision direction
```

This gate should be applied only when the manuscript's claims require it. Do not expose gate names or pattern IDs in final referee reports.
