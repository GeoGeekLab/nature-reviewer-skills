# Reproducibility, data and code gate

Check whether basin boundaries, station IDs, masks, product versions, quality flags, model configs, forcing data, scenario files, splits, seeds and scripts are sufficient to reproduce main analyses.

Preferred internal pattern:

```text
Claim type -> evidence risk -> reviewer concern -> revision direction
```

This gate should be applied only when the manuscript's claims require it. Do not expose gate names or pattern IDs in final referee reports.
