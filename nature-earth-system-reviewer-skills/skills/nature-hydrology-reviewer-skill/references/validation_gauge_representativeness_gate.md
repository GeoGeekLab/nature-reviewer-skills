# Validation and gauge representativeness gate

Check whether validation is independent and representative across basins, hydroclimates, flow regimes, terrain, river sizes and human regulation. Watch for data-rich-region bias and ungauged-basin overclaiming.

Preferred internal pattern:

```text
Claim type -> evidence risk -> reviewer concern -> revision direction
```

This gate should be applied only when the manuscript's claims require it. Do not expose gate names or pattern IDs in final referee reports.
