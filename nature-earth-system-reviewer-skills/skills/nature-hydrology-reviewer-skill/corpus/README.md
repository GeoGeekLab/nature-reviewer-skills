# Corpus metadata package

This folder records metadata and QA artifacts for the best-effort source corpus used to create nature-hydrology-reviewer-skill-v1.0.

It does not contain raw Peer Review PDF files.

Files:

- `index.csv`: article-level source metadata.
- `failures_excluded.csv`: excluded or deferred candidates.
- `keyword_expansion.csv`: search keyword classes.
- `qa_report.csv`: corpus QA metrics.
- `checksums.sha256`: SHA256 checksums of source PDFs from the local corpus build.
- `summary.json`: compact corpus and distillation summary.
- `corpus.zip`: zipped metadata-only corpus artifacts, not raw PDFs.
