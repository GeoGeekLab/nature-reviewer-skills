# Release notes: nature-hydrology-reviewer-skill-v1.0

## v1.0

Initial release of a Nature-style hydrology reviewer skill.

Included:

- Hydrology-centered `SKILL.md`.
- 16 reference gate files.
- 148 abstracted non-verbatim reviewer patterns.
- Non-verbatim source and reviewer-unit metadata.
- Classic Nature/Science hydrology stress-test source anchors with a strict non-weighting rule.
- Nature-style review templates and example report.
- Validation, DOCX rendering and CI scripts.
- Dual license: MIT OR Apache-2.0.

Known limits:

- The source corpus is best-effort, not official or complete.
- Raw peer-review PDFs are not redistributed.
- The skill assists review writing but does not replace expert peer review or editorial judgment.
