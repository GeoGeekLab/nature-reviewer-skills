# Source basis and provenance

This repository is derived from a public, best-effort Nature Portfolio hydrology peer-review corpus collected for nature-hydrology-reviewer-skill-v1.0.

## Inclusion basis

Papers were included when the central claim depended on hydrological variables, hydrological processes, hydrological models, hydrological remote sensing, water-resource systems, water-quality transport or basin-scale water-cycle evidence.

Default inclusion: research Article / Article-type papers with downloadable Peer Review File or Transparent Peer Review File.

Default exclusion: Review, Perspective, Comment, News, Editorial, Correspondence, Protocol, Brief Communication, Matters Arising, Correction and Retraction.

## Repository redistribution policy

This GitHub-ready skill repository does not redistribute raw Peer Review PDF files. It stores only:

- article-level metadata;
- SHA256 checksums of source PDFs;
- non-verbatim reviewer-unit indices;
- abstracted reviewer patterns;
- gate definitions;
- templates, examples, scripts and tests.

Do not use this repository to identify anonymous reviewers or reconstruct source peer-review files.


## Cross-literature stress-test sources

The executable reviewer memory also contains a small non-weighted layer of abstract stress tests from high-impact Nature and Science hydrology debates. These are source anchors for recurring evidence-chain risks, not redistributed review text and not a replacement for the peer-review-file corpus.

The stress-test index is stored in `_internal/classic_stress_test_index.csv`. It records only bibliographic anchors, abstracted axes, intended reviewer use and the non-weighting rule.
