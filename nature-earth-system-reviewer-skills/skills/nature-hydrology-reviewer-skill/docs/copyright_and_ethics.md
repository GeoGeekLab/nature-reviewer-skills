# Copyright and ethics note

This repository is designed to avoid redistribution of long original peer-review comments. The reviewer memory is abstracted into transferable patterns and gates.

Rules:

- Do not include raw Peer Review PDF files in this repository.
- Do not include long original reviewer comments.
- Do not identify or attempt to identify anonymous reviewers.
- Do not present this skill as an official Nature Portfolio tool.
- Preserve source provenance at article-metadata level only.
- Use the skill to generate new manuscript-specific reviews, not to reconstruct historical reviews.
