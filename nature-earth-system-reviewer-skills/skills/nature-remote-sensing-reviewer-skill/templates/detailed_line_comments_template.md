# Detailed Locatable Comments Template

Use this template when a full manuscript has enough readable text for specific comments.

## Specific comments

1. `[Line/Page/Paragraph/Figure/Table anchor]` [comment tied to the exact location].
2. `[Line/Page/Paragraph/Figure/Table anchor]` [comment tied to wording, method, evidence, figure, table, equation, or supplement].
3. `[Data availability / Code availability / Supplement label]` [comment on reproducibility or consistency].

Anchor rules:

- Use real line ranges only when present in the manuscript or PDF extraction.
- If no line numbers exist, use generated paragraph anchors from `review_inputs_extracted/*_anchored.md`.
- Use figure/table/equation labels whenever they are more stable than generated text anchors.
- Do not fabricate page or line numbers.
