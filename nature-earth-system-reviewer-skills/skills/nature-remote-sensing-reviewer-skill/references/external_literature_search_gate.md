# External Literature Search Gate

Use external literature retrieval to improve novelty assessment, method comparison, and technical critique when retrieval is allowed. The goal is not to add many citations; it is to identify highly related published work and established methods that change the evaluation of the submitted manuscript.

## When to search

Search when the manuscript makes one or more of the following claims:

- new, first, unprecedented, global, regional, long-term, or operational product;
- a new retrieval method or model architecture;
- a major trend, breakpoint, attribution, or policy implication;
- a method that should be compared with established approaches;
- a claimed improvement over prior products or algorithms.

## Search targets

Prioritize:

- papers with the same target variable or phenomenon;
- papers using similar sensors, products, or predictors;
- papers in the same or comparable study setting;
- papers using similar validation or attribution designs;
- method papers that introduced the analysis the reviewer recommends.

## Safety rules

- Do not search when the user explicitly forbids it.
- Do not invent results when search is unavailable.
- Use verified bibliographic details only.
- In the author-facing report, compare against only the most relevant works; put search details in the internal audit.
- Distinguish "not found" from "not searched".
