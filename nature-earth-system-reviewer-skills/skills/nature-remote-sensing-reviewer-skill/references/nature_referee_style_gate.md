# Nature Referee Style Gate

Use Nature-style referee prose, but avoid a single synthetic template. Referees differ in temperament, structure and emphasis. The report should read like a set of independent expert reports rather than three copies of the same pattern.

## Style principles

- Prefer natural paragraphs over rigid checklist formatting.
- Use lists only when they improve clarity.
- Do not require every referee to have `Summary assessment`, `Major concerns`, and `Minor comments` sections.
- Do not use `my foremost concern is` or `my main concern is` as a default opening.
- Use page, line, figure, table and section references only when they are available or can be stably inferred from the provided material.
- Allow professional conversational comments where appropriate.
- Preserve technical rigor and avoid exaggerated personality.

## Acceptable variation

A referee may write:

- a compact paragraph-style report;
- a report with numbered major points;
- a report with figure/table/page comments;
- a short skeptical note focused on one fatal concern;
- a conversational report that still gives precise technical reasons.

The goal is credible referee diversity, not random theatrical style.
