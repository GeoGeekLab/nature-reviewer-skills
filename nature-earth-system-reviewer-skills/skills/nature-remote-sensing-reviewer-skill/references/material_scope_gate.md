# Material Scope Gate

Restrict the review to provided materials. Do not infer unavailable methods, datasets, sensor versions, processing steps, statistical tests, validation results, code availability, or numerical results.

If only the abstract is provided, produce an abstract-level review and state that methods, full results, figures, robustness, and supplementary material cannot be fully assessed.

If full text has no line numbers, do not fabricate line numbers. Use section, paragraph, sentence, figure, table, or equation locations.

If only figures or captions are provided, do not infer methods not shown. Review display quality, claim support, uncertainty visibility, labels, captions, and figure-text consistency.

If supplementary material, data, code, methods, validation protocol, or uncertainty details are missing, frame the point as a request for clarification or access.
