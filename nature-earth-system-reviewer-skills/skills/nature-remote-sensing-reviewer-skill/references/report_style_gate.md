# Report Style Gate

The author-facing output should resemble a Nature / Nature Communications peer-review file. Use `references/nature_referee_format_gate.md` and `references/nature_referee_style_gate.md` as the controlling style references.

Write for authors. Use formal, specific, technically grounded prose. Recognize contribution before critique. Explain why each concern matters and what additional analysis, clarification, or claim calibration would resolve it.

Avoid default editorial recommendation language. Do not write explicit recommendation headings unless the user explicitly asks for an editorial recommendation.

Use natural paragraphs before lists. Use `Minor comments:` for wording, notation, figure, table, page/line, and micro-consistency issues.

Do not use scoring rubrics, classroom tone, generic praise, private editor-only language, or a compliance checklist inside the author-facing report.
