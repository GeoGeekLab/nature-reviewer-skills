# Nature Referee Format Gate

The default author-facing output should resemble a Nature / Nature Communications peer-review file.

Use this structure:

```text
Reviewer Reports on the Initial Version:
Referees' comments:

Referee #1 (Remarks to the Author):

[Opening paragraph that recognizes the manuscript's contribution and frames the broad concern.]

[Natural-prose paragraph for the foremost concern.]

[Additional major concerns in natural prose.]

Minor comments:
1. [Supported page/line/section/figure/table comment.]
```

Do not default to internal-audit headings in the author-facing report, including "Overall recommendation", "Summary assessment", "Major concerns", "Essential revisions", or "Blind-test compliance check". Use those only in a separate internal audit when requested or useful.

Avoid explicit accept/reject language unless the user requests an editorial recommendation. Prefer evidence-proportional language such as "the present evidence is not yet sufficient to support the journal-level claim" or "the manuscript would require substantial additional analysis before this conclusion could be supported."
