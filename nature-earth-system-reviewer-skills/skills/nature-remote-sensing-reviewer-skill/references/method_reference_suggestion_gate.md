# Method Reference Suggestion Gate

When recommending additional methods, cite or suggest established methodological references where doing so helps the author understand the requested analysis. This is optional, not a requirement for every comment.

## Rules

- Suggest method references only when the method is directly relevant to a weakness in the manuscript.
- Prefer original or canonical method papers, authoritative reviews, or widely used methodological references.
- Do not invent citations. Use only references present in the manuscript, verified through allowed retrieval, or stored in the local method-reference memory.
- If a method family is useful but no verified citation is available, name the method generically without a citation.
- Do not turn the review into a literature survey.

## Appropriate uses

Examples of appropriate method-reference suggestions include:

- trend decomposition or breakpoint detection when a manuscript makes a temporal-change claim;
- field significance or false-discovery-rate control when a manuscript maps many spatial p-values;
- spatially blocked validation when a geospatial model claims spatial generalization;
- reference-data uncertainty and validation standards when a satellite product relies on field observations;
- causal inference references when a manuscript makes policy, intervention, or driver claims.

## Author-facing phrasing

Use brief formulations:

- "The authors might consider a seasonal decomposition or breakpoint framework, rather than relying only on a single linear trend."
- "A field-significance or false-discovery-rate framework would be more appropriate for the pixel-wise tests."
- "Spatially blocked or leave-region-out validation would be needed to show spatial generalization."
- "If the authors intend a causal interpretation, the estimand and identification assumptions should be made explicit."

Add citations sparingly and only when verified.
