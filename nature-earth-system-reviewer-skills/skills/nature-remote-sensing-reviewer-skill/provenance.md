# Provenance

This skill is based on a distilled corpus of 71 public Nature and Nature Communications peer-review PDFs relevant to remote sensing. Raw PDF files are not included.

The package contains derived document metadata, cleaned reviewer behavior units, issue patterns, contribution patterns, style moves, style motifs, referee voice profiles, method-reference patterns, gates, templates, scripts, and synthetic examples.

The reviewer memory contains 4,299 cleaned reviewer/referee units extracted from formal reviewer-report zones across all 71 source PDFs. Author rebuttal zones are excluded. Reviewer identities are not inferred or exposed beyond public generic labels such as `Referee #1`.

The skill uses manuscript-content-based gate routing. Trend, sampling, validation, inference-integrity, published-paper comparison, method-reference, and editorial-assessment checks are applied only when triggered by the submitted manuscript's own claims and materials.

The package does not contain raw PDFs or external literature snapshots. External literature comparisons and method references must be verified at review time when retrieval is allowed, or drawn from references already provided in the manuscript.
