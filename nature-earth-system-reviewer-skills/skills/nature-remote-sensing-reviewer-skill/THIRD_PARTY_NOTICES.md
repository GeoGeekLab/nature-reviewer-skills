# Third-Party Notices

Original peer-review PDFs are third-party public materials. This package contains derived metadata, cleaned and distilled behavior representations, paraphrased issue patterns, templates, scripts, and synthetic examples. Raw PDF files are intentionally excluded.

The package does not attempt to identify anonymous reviewers. It supports role-level Nature-style referee behavior only.

External literature used during a review must be verified at review time or supplied by the user. The package does not include snapshots of external papers.
