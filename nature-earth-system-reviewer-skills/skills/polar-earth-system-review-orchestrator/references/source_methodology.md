# Source methodology

The source set combines Nature Portfolio public peer-review files, open interactive referee comments from The Cryosphere Discussions, and official cryosphere/product/research-governance documents. Files were downloaded to a temporary analysis cache, hashed, page-counted, text-extracted where encoding permitted, and first-page rendered for visual verification. Distillation was performed at the claim-risk-gate-revision level. No sentence from an anonymous referee is stored as an executable pattern.
