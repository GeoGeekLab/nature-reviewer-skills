# Source basis

This skill is based on a best-effort corpus of publicly accessible Nature Portfolio peer-review files in climate sciences and ecology.

The package contains abstracted reviewer concern patterns, gate definitions, source metadata and high-level stress tests. It does not contain raw reviewer reports or peer-review PDFs.

Corpus snapshot:

- Source peer-review PDFs: 63
- Source articles represented in distilled units: 61
- Distilled reviewer-comment units: 5774
- Abstracted reviewer patterns: 112
- Raw reviewer text included: no

The cross-literature stress-test layer captures recurring high-level evidence risks from public debate, reanalysis and response records. It is used only when a manuscript makes the same type of claim.

This is a best-effort research-assistance corpus, not an official journal dataset or complete index.
