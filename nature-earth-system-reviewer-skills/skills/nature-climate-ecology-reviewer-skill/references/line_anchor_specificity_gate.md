# Line, page, paragraph and figure anchor specificity gate

## Purpose

Ensure reviews contain locatable comments rather than only broad thematic critique.

## Use anchors in this order

1. Real manuscript line numbers, if available.
2. Page numbers and section headings.
3. Paragraph anchors generated from extracted text.
4. Figure, table, equation, method subsection, data availability, code availability, or supplement anchors.

## Reviewer expectations

- Tie major concerns to the relevant result, method, figure, claim or supplement location.
- Include specific comments that test definitions, units, baselines, sample sizes, thresholds, parameters, captions and data/code statements.
- Do not invent line numbers.
- If text extraction is incomplete, state the limitation and use available anchors.

## Typical anchor targets

- title and abstract claim language;
- field site description and sampling frame;
- measurement and proxy definition;
- model assumptions and parameter tables;
- uncertainty and sensitivity analysis;
- figure captions, map legends and color scales;
- data/code availability statements;
- supplementary validation and robustness tests.
