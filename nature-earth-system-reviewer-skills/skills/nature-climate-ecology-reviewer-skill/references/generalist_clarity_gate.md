# Generalist readability and conceptual clarity gate

## Purpose
Use this gate when a manuscript makes claims related to generalist readability and conceptual clarity.

- `reader`

- `terminology`

- **CECO-P0010** (abstracted_reviewer_concern): Methods needed to judge the central claim should be in the main text or clearly signposted, not hidden behind unexplained supplement references.

## Evidence expected before accepting the claim

- defined terms
- clear units
- figure/table interpretability
- main-text methods sufficient for assessment

## Typical claim-language risk

- hiding central logic behind jargon or unclear figures

## Output expectation

When this gate is triggered, write reviewer comments that are claim-specific, evidence-chain aware, and calibrated to the manuscript's actual scope. Prefer explicit tests or revisions over generic requests.

## Additional stress tests

- Define core terms such as restoration, forest, degradation, resilience, tipping point, safe boundary, ecosystem function, carbon sink and sequestration at first use.
- Ensure the abstract and figures communicate uncertainty and evidence boundaries, not only headline significance.
- Check whether conceptual diagrams or maps imply stronger causal or spatial precision than the analysis supports.
