Reviewer Reports on the Initial Version:

Referees' comments:

Referee #1 (Remarks to the Author):

The manuscript addresses an important climate-ecology question. The central concern is whether the main conclusion is supported at the same scale and strength as claimed.

1. The novelty should be positioned more clearly against the closest prior work.
2. The title and abstract should distinguish directly observed evidence from modelled or inferred implications.

Referee #2 (Remarks to the Author):

The methods are potentially appropriate, but several details are needed to judge robustness.

1. The authors should report how sensitive the main result is to the spatial mask, baseline period and model assumptions.
2. The uncertainty treatment should be connected to the headline quantities.

Referee #3 (Remarks to the Author):

The broader ecological implications are plausible but not fully established.

1. The manuscript should separate physical exposure pathways from demonstrated ecosystem impacts.
2. Data and code availability should include the analysis workflow, not only figure-generation scripts.
