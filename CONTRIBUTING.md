# Contributing

1. Preserve original pattern records and provenance fields.
2. Add new normalized aliases in `nature_reviewer_core.patterns`; do not rewrite source databases merely to fit one schema.
3. Add or update benchmark cases for behavior-changing modifications.
4. Run `make all` before opening a pull request.
5. Do not commit manuscript data, unpublished peer reviews, credentials, raw copyrighted review reports, or extracted sensitive content.
6. New scientific benchmark gold labels require at least two domain experts, an adjudication record, and inter-rater agreement reporting.
